# Docker 重启后按原三终端回放

当前电脑的 `~/ROS_Noetic_Docker/run.sh` 使用 `docker run --rm`：退出容器后，
容器内单独安装的 `~/fusion_ws` 和 `~/venvs` 会消失。项目目录
`~/catkin_ws/fusion_inbox` 由宿主机挂载进容器，因此本项目现在直接从该
目录加载 ROS 包；CPU Python 环境保存在同一挂载下的
`~/catkin_ws/venvs/fusion_cpu`。继续使用原镜像 `ros-noetic-dev:latest`。

## 进入容器

若容器尚未运行，在 Fedora 宿主机执行原来的启动脚本：

```bash
~/ROS_Noetic_Docker/run.sh
```

之后在宿主机再开三个终端，各执行一次：

```bash
docker exec -it ros-noetic bash
```

## 终端 1：回放 master

```bash
source ~/catkin_ws/fusion_inbox/deploy/offline_env.bash
roscore -p 11321
```

若 11321 的 `roscore` 已运行，保留它即可，不要再次启动。

## 终端 2：检测与 RViz

```bash
source ~/catkin_ws/fusion_inbox/deploy/offline_env.bash
rosparam set /use_sim_time true
roslaunch image_pointcloud_fusion c32_live.launch \
  model:=/home/baishui/catkin_ws/fusion_inbox/best.pt \
  imgsz:=640 max_hz:=1.0
```

等待日志中的 `CPU fusion ready`，再开始回放。没有图形显示时可加
`rviz:=false`，检测节点仍会运行。

## 终端 3：bag

```bash
source ~/catkin_ws/fusion_inbox/deploy/offline_env.bash
rosbag play --clock --pause -r 0.2 \
  ~/catkin_ws/fusion_inbox/my_30s_all.bag \
  --topics /stereo_inertial_publisher/color/image /velodyne_points
```

在终端 3 按**空格**开始播放。播放完毕后若要重播，重新运行终端 3 命令；
终端 1、2 可保持运行。

## 若再次提示找不到 ROS 包

在终端 2 先检查：

```bash
source ~/catkin_ws/fusion_inbox/deploy/offline_env.bash
rospack find image_pointcloud_fusion
echo "$FUSION_PYTHON"
```

应分别显示 `~/catkin_ws/fusion_inbox/image_pointcloud_fusion` 的绝对路径
和 `~/catkin_ws/venvs/fusion_cpu/bin/python` 的绝对路径。若未显示，先确认
容器仍把宿主机 `~/catkin_ws` 挂载到容器相同路径。
